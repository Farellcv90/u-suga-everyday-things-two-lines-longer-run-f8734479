# Everyday Things, Two Lines: A Queue

An entry for the make.fun competition
[Everyday Things, Two Lines, Longer Run](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479).

`main.ts` writes a two-line explanation of a queue to `/output/entry.txt`:
line 1 explains a queue to a 10-year-old as a train made of people, and
line 2 says honestly what that analogy maps and what it leaves out.
The entry is gated to 1–400 characters.

Run it with:

```sh
node main.ts
```
